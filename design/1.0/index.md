# Dawnwell 1.0 — макеты экранов

Восстановлено из кода последнего коммита версии 1.0. Каждый экран снят в светлой и тёмной теме (iPhone, en_US), файлы в `screens/`.

| # | Экран | Что показано |
|---|-------|--------------|
| 01 | Today | Главный экран с данными |
| 02 | Progress | Прогресс (бесплатная версия) |
| 03 | Report | Отчёт (бесплатная версия) |
| 04 | Learn | Раздел статей |
| 05 | Progress — Plus | Прогресс с открытым Plus |
| 06 | Report — Plus | Отчёт с открытым Plus |
| 07 | Today — пусто | Главный экран без записей |
| 08 | Progress — пусто | Прогресс без записей |
| 09 | Report — пусто | Отчёт без записей |
| 10 | Onboarding — Welcome | Первый экран онбординга |
| 11 | Onboarding — Tablet | Выбор препарата |
| 12 | Onboarding — Goals | Цели |
| 13 | Medication | Препарат, время, остаток таблеток, напоминания |
| 14 | Your data | Данные, файл резервной копии, копии на телефоне |
| 15 | Your data — восстановление | Подтверждение замены данных копией |
| 16 | Your data — ошибка файла | Файл не удалось открыть |
| 17 | Add food | Добавление еды |
| 18 | Symptom details | Симптом (тошнота) |
| 19 | Symptom — хороший день | Отметка самочувствия |
| 20 | Paywall | Dawnwell Plus |
| 21 | Storage problem | Не удалось открыть данные (данные не удалены) |
